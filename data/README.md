# Локальная база рецептов

При первом запуске `npm start` сервер скачивает `unitools-recipes-v1.json` в эту папку. Файл занимает около 2,6 МБ и затем читается только с локального диска через `/api/recipes`.

Источник: [UniTools World Recipes](https://theunitools.com/ru/data), лицензия CC BY-SA 4.0. В карточке каждого рецепта сайт показывает атрибуцию источнику и лицензию.
